## Instruções para Execução do Projeto
- 1. Clone o repositório no Github



- 2. Entre na pasta do projeto:
cd ConsultaFacil

- 3. Entre na pasta do backend:
cd backend

- 4. Instale as dependências:
npm install

- 5. Inicie o servidor:
npm start

- 6. Abra no navegador o arquivo:
frontend/index.html
